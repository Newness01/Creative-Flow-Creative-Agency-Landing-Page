# Creative Flow

Creative Flow is a modern creative agency landing page built with Next.js and Tailwind CSS. It is designed to showcase services, portfolio work, blog content, and a contact flow in a polished one-page experience.

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS v4
- TypeScript
- AOS for scroll animations
- react-parallax-tilt for portfolio effects

## Features

- Hero section with strong agency-style messaging
- About, services, work process, portfolio, blog, and contact sections
- Responsive navigation and mobile menu
- Animated scroll reveals
- Contact form layout and contact info cards

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - create a production build
- `npm run start` - run the production server
- `npm run lint` - run ESLint

## Suggested GitHub Name

If you want the repository name to match the site branding, use `creative-flow`. If you want it to be more explicit, use `creative-flow-website`.

## Project Structure

- `app/` - app router pages, layout, and global styles
- `Components/` - reusable homepage sections and shared UI
- `public/images/` - assets used across the landing page

## Notes

This project currently uses placeholder text and sample content in a few sections, so it is ready for you to replace with real agency copy, case studies, and contact details.
